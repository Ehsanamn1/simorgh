# مدار — سامانه‌ی یکپارچه‌ی مدیریت مزرعه و عملیات

مدار یک سامانه‌ی عملیات کسب‌وکار برای مدیریت سایت‌ها و مزارع، تولید، سفارش، شرکا و تأمین‌کنندگان، انبار، ارسال، کیفیت، امور مالی، اهداف و تاریخچه‌ی تغییرات است. سامانه به یک صنعت یا محصول خاص محدود نیست.

## ورود مستقیم به محیط عملیاتی

نشانی اصلی وارد مسیر عملیاتی می‌شود، اما تا پیش از ورود، فرم امن ورود و بازیابی رمز روی آن قرار می‌گیرد؛ هیچ انتخاب نقش نمایشی، اطلاعات محرمانه را باز نمی‌کند. مدیر، شریک مزرعه، راننده و مشتری پس از فعال شدن حساب معتبر، محیط مخصوص نقش واقعی خودشان را می‌بینند. نقش از عضویت سمت سرور تعیین می‌شود، نه از یک انتخابگر نمایشی.

مرکز فرمان شامل شاخص‌های داده‌محور، استثناهای نیازمند اقدام، سفارش‌های اخیر، نقشه‌ی سایت‌های دارای مختصات واقعی، اهداف، برنامه و دسترسی سریع به عملیات است. این نقشه فقط پس از ثبت مختصات GPS واقعی نشانگرها را فعال می‌کند. در موبایل نوار اصلی چهار بخش دارد و ناوبری کامل از دکمه‌ی «بیشتر» در دسترس است. ظاهر کاملاً فارسی، راست‌چین و مبتنی بر فونت وزیر است؛ پوسته‌ی روشن/تاریک ذخیره می‌شود.

## داده و دسترسی

کاربر مهمان می‌تواند پوسته‌ی عملیاتی را ببیند، اما فرم ورود امن روی آن قرار می‌گیرد؛ اطلاعات خصوصی شرکت خوانده نمی‌شود و امکان نوشتن وجود ندارد. مقدارهای محرمانه مانند آمار سفارش، ظرفیت، مالی و GPS فقط پس از ایجاد حساب مالک و عضویت مناسب از Supabase و تحت RLS خوانده می‌شوند. عدد نمونه یا نشانگر مکانی جعلی ساخته نمی‌شود.

- [راهنمای ساخت حساب مالک](docs/OWNER_PROVISIONING.md)
- [تطبیق اجزای مرجع با صفحه‌ها و قرارداد داده](docs/REFERENCE_BOARD_MAPPING.md)
- [راهنمای ساخت اپ بومی موبایل](docs/MOBILE_APP.md)

CI بررسی‌های TypeScript، Lint، تست واحد، مسیر فایل‌های GitHub Pages و تست‌های Playwright در اندازه‌های مختلف صفحه را اجرا می‌کند. برای Android بسته‌ی debug جهت آزمون داخلی ساخته می‌شود؛ انتشار فروشگاهی به امضای انتشار نیاز دارد. بسته‌ی iOS فعلاً برای شبیه‌ساز است و برای آیفون واقعی باید با حساب توسعه‌دهنده‌ی Apple امضا شود.

## محدودیت‌های شناخته‌شده

- حساب مالک و عضویت اولیه باید از مسیر امن Supabase ساخته شوند؛ هیچ گذرواژه‌ی پیش‌فرضی در پروژه قرار ندارد.
- صف نوشتن آفلاین و حل تعارض، اعلان‌های زمان‌بندی‌شده و همه‌ی اتوماسیون‌های هوش مصنوعی هنوز تکمیل نشده‌اند.
- نقشه‌ی سایت‌ها مختصات واقعی ذخیره‌شده را نمایش می‌دهد؛ مسیرها و نشانگرهای محموله همچنان به داده‌ی مکانی معتبر و دسترسی مجاز نیاز دارند.
