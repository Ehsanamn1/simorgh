# سیمرغ — سامانه‌ی یکپارچه‌ی مدیریت مزرعه و عملیات

سیمرغ یک سامانه‌ی عملیات کسب‌وکار برای مدیریت سایت‌ها و مزارع، تولید، سفارش، شرکا و تأمین‌کنندگان، انبار، ارسال، کیفیت، امور مالی، اهداف و تاریخچه‌ی تغییرات است. سامانه به یک صنعت یا محصول خاص محدود نیست.

## ورود مستقیم به محیط عملیاتی

نشانی اصلی مستقیماً به **مرکز فرمان شبکه** می‌رود؛ صفحه‌ی معرفی، انتخاب نقش ساختگی و فرم ورود عمومی در مسیر اصلی قرار ندارند. مدیر، شریک مزرعه، راننده و مشتری پس از فعال شدن حساب معتبر، محیط مخصوص نقش واقعی خودشان را می‌بینند. نقش از عضویت سمت سرور تعیین می‌شود، نه از یک انتخابگر نمایشی.

حساب‌های از قبل ایجادشده از دکمه‌ی «ورود مدیر و اعضا» وارد می‌شوند و مسیر بازیابی گذرواژه نیز در دسترس است؛ ثبت‌نام عمومی غیرفعال می‌ماند. نقش کاربر فقط از عضویت معتبر سمت سرور تعیین می‌شود.

مرکز فرمان شامل شاخص‌های داده‌محور، استثناهای نیازمند اقدام، سفارش‌های اخیر، نقشه‌ی پایه، اهداف و برنامه، روند عملکرد و دسترسی سریع به سفارش، انبار، وظایف و مالی است. در موبایل نوار اصلی چهار بخش دارد و ناوبری کامل از دکمه‌ی «بیشتر» در دسترس است. ظاهر کاملاً فارسی، راست‌چین و مبتنی بر فونت وزیر است؛ پوسته‌ی روشن/تاریک ذخیره می‌شود.

## داده و دسترسی

حالت بدون حساب، محیط عملیاتی را از نظر چیدمان و مسیر ماژول‌ها نشان می‌دهد، اما اطلاعات خصوصی شرکت را نمی‌خواند و امکان نوشتن ندارد. مقدارهای محرمانه مانند آمار سفارش، ظرفیت، مالی و GPS فقط پس از ایجاد حساب مالک و عضویت مناسب از Supabase و تحت RLS خوانده می‌شوند. عدد نمونه یا نشانگر مکانی جعلی ساخته نمی‌شود.

- [راهنمای ساخت حساب مالک](docs/OWNER_PROVISIONING.md)
- [تطبیق اجزای مرجع با صفحه‌ها و قرارداد داده](docs/REFERENCE_BOARD_MAPPING.md)
- [راهنمای ساخت اپ بومی موبایل](docs/MOBILE_APP.md)

CI بررسی‌های TypeScript، Lint، تست واحد، مسیر فایل‌های GitHub Pages و تست‌های Playwright در اندازه‌های مختلف صفحه را اجرا می‌کند. برای Android بسته‌ی debug جهت آزمون داخلی ساخته می‌شود؛ انتشار فروشگاهی به امضای انتشار نیاز دارد. بسته‌ی iOS فعلاً برای شبیه‌ساز است و برای آیفون واقعی باید با حساب توسعه‌دهنده‌ی Apple امضا شود.

## محدودیت‌های شناخته‌شده

- حساب مالک و عضویت اولیه باید از مسیر امن Supabase ساخته شوند؛ هیچ گذرواژه‌ی پیش‌فرضی در پروژه قرار ندارد.
- صف نوشتن آفلاین و حل تعارض، اعلان‌های زمان‌بندی‌شده و همه‌ی اتوماسیون‌های هوش مصنوعی هنوز تکمیل نشده‌اند.
- نقشه‌ی عمومی فقط نقشه‌ی پایه را نشان می‌دهد؛ نشانگرهای محموله به مختصات واقعی و دسترسی مجاز وابسته‌اند.


## Product scope

The authenticated manager workspace provides role-filtered modules for orders, goals, customers, suppliers, inventory, capacity, quality, shipments, finance, farm sites, production cycles/batches, daily production, tasks, incidents, partner settlements and audit history.

The manager control tower includes a live map that uses only farm-site coordinates stored in Supabase. Farm units, production cycles and daily records are generic across agricultural sectors; there is no hard-coded quail requirement.
