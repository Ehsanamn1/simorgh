# مدار — ساخت حساب و فضای کاری

## ثبت‌نام و ورود

فرایند اولیه فقط دو ورودی دارد:

- **نام کاربری:** ۳ تا ۳۲ نویسه؛ حروف فارسی یا انگلیسی، عدد، نقطه، خط تیره و زیرخط مجازند. نام کاربری نباید با نقطه یا خط تیره شروع یا تمام شود.
- **رمز عبور:** ۸ تا ۱۲۸ نویسه.

ایمیل، شماره موبایل، تأیید پیامکی، نام کامل، نام مجموعه و تکرار رمز عبور برای ثبت‌نام لازم نیستند. پس از ثبت‌نام، مدار نام نمایشی را از نام کاربری و نام فضای کاری را به‌صورت خودکار می‌سازد و حساب را به‌عنوان مالک همان فضای کاری جداگانه ثبت می‌کند.

برای ورود فقط همان نام کاربری و رمز عبور استفاده می‌شوند. رمز عبور یکتا و قوی بساز و آن را در password manager نگه‌دار. بازیابی خودکار رمز عبور در این نسخه فعال نیست.

## پیوستن به مجموعهٔ موجود

ساخت حساب، یک فضای کاری مستقل می‌سازد. برای اتصال به مجموعه‌ای موجود، مالک یا مدیر آن مجموعه باید از بخش دسترسی کاربران کد دعوت صادر کند. پس از ورود به حساب، کد دعوت در بخش «پیوستن به مجموعه» وارد می‌شود. انتخاب نقش به‌تنهایی دسترسی ایجاد نمی‌کند؛ عضویت باید از دعوت معتبر سمت سرور تأیید شود.

- برای نقش‌های `customer` یا `supplier` باید حساب مشتری یا تأمین‌کنندهٔ همان مجموعه به دعوت متصل باشد.
- فقط مالک می‌تواند نقش `admin` دعوت کند.
- کد خام دعوت را در ticket عمومی، log یا commit قرار نده. دیتابیس hash آن را ذخیره می‌کند.

## نقش‌ها و حفاظت از داده‌ها

- `owner`: مدیریت فضای کاری و دعوت مدیران.
- `admin`: مدیریت اعضا و عملیات مجاز، بدون امکان دعوت مدیر جدید.
- `staff`: عملیات داخلی مجاز، بدون دسترسی خودکار به تنظیمات مدیریتی مختص مالک/مدیر.
- `customer`, `supplier`, `driver`: دسترسی محدود به رکوردهای مرتبط با همان شرکت و نقش.

محدودهٔ رکوردها باید در Worker سمت سرور تعیین شود. پیش از استفادهٔ تجاری، جداسازی tenant و role را با حساب‌های جداگانه بررسی کن.

## وضعیت دیتابیس و انتشار

نسخهٔ عملیاتی از Cloudflare Worker و Neon استفاده می‌کند. سبز بودن build به‌تنهایی اثبات سلامت سرویس زنده نیست؛ پاسخ `/api/health` و ساخت حساب از مرورگر باید بعد از انتشار آزمایش شوند.

مهاجرت `0011_username_password_only.sql` ستون‌های شمارهٔ موبایل را اختیاری می‌کند و حساب‌ها یا داده‌های موجود را حذف نمی‌کند.

## قواعد امنیت

- رمز عبور، کد دعوت و secretهای محیط را در گفتگو یا مخزن قرار نده.
- `DATABASE_URL` و Cloudflare API token فقط در GitHub Actions Secrets / Cloudflare secrets قرار می‌گیرند؛ هرگز در `VITE_*` یا bundle مرورگر نگذار.
- برای جلوگیری از brute force، درخواست‌های ناموفق محدود می‌شوند. در صورت خطای محدودیت نرخ، پس از گذشت زمان اعلام‌شده دوباره تلاش کن.
